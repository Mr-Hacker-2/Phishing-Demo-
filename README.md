# Phishing Awareness Demo

This is a browser-based training simulation designed to show warning signs of a fake login page. It is an educational demo, not a real authentication service.

## Run locally

Open `index.html` in a modern browser. The page uses some externally hosted visual assets, so a network connection may be needed to load its styling.

## Privacy-safe behavior

The demo has been updated so that it does not display typed usernames or passwords in its fake console, does not claim to save credentials, and does not transmit form contents. Use fictional test values only.

## Learning goals

- Check the domain and URL before entering credentials.
- Be cautious of urgency, free rewards, and suspicious login prompts.
- Use a password manager and multifactor authentication where available.
- Report suspected phishing through the service's official reporting process.

## Safety

Do not copy this page to impersonate a real service or collect anyone's credentials. Keep demonstrations clearly labeled as training, and get permission before using them with other people.
